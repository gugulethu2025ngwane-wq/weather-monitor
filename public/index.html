Settings

ESP32 WebSocket address:

The ESP32 should send JSON like:
{"temp":26.4,"humidity":58,"pressure":1012,"wind":14.2,"rain":0,"battery":72,"voltage":3.98,"source":"solar"}

source is "solar", "turbine" or "none". You can also send "solar":true,"turbine":false instead. Only one source can be active at a time. If both are sent as true, solar is shown.

Demo data stops automatically when the first real reading arrives.

About

ESP32 → WebSocket (/esp32) → Node.js server → Socket.IO → this page. Shows five weather sensors (temperature, humidity, air pressure, wind speed, rainfall), the battery level, and which energy harvester is working. Solar and the wind turbine never run together: when one is active, the other is paused.
